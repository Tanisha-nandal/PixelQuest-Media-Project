# PixelQuest Media Project

## Overview
A collaborative media project for organizing assets, source files, documentation, and tests.

## Repository Structure
- Assets: 3D models, textures, audio, animations, and concept art.
- Source: scripts and shaders.
- Documentation: design and security documents.
- Tests: testing resources.

## Branching Strategy
- main: stable project files.
- development: ongoing integration.
- feature branches: individual tasks.
